## 三、流程清单

### 3.1 订单履约主流程（核心链路）

```
[订单导入] → [订单中心状态机] → [库存分配] → [拣货] → [复核] → [打包] → [批量打印面单] → [出库]
```

| 步骤 | 触发 | 操作角色 | 系统动作 | 状态流转 |
|---|---|---|---|---|
| 1. 导入 | 店小秘 Excel 导出 | admin | 模板识别→字段映射→校验→幂等去重→YUN 过滤→标记规则→预览/错误报告 | 生成 package（unassigned） |
| 2. 分配 | 订单入库 | 系统 | 库存校验（组合按 BOM 展开）、可用库存锁定 | unassigned → assigned（或 shortage_hold） |
| 3. 拣货 | 分配完成 | picker | 生成拣货任务、路径排序、扫码确认 | assigned → picking → checked |
| 4. 复核 | 拣货完成 | checker | 核对明细、异常上报 | picking → checked 或 manual_review |
| 5. 打包 | 复核通过 | packer | 打包、包裹标签打印 | checked → packed |
| 6. 打印 | 打包完成 | packer/shipper | 批量打印面单（云途 API，凭运单号）、快递单号回填 | packed（label_printed=1） |
| 7. 出库 | 面单已打印 | shipper | 出库确认、库存扣减、流水留痕 | packed → outbound |

### 3.2 异常与旁路流程

| 流程 | 触发条件 | 处理 | 状态流转 |
|---|---|---|---|
| 拦截出库 | 订单含 `CS99` | 进异常队列，人工处理 | → intercepted |
| 强制复核 | 订单含 `CS00` | 强制人工复核 | → manual_review |
| 缺货挂起 | 库存不足（组合按 BOM 展开比对） | 挂起，等补货/采购 | → shortage_hold |
| 数量不一致 | 8 处「2 SKU 总数 4/6」 | 进人工复核队列，不自动均分 | → manual_review |
| 补发包裹 | 包裹号 `R1` 后缀 | 视为新包裹，不关联原单 | 新 package |

### 3.3 采购流程

```
[采购单] → [下单] → [到货签收] → [质检] → [上架 或 快进快出直分] → [完成]
```

| 步骤 | 触发 | 角色 | 系统动作 | 状态流转 |
|---|---|---|---|---|
| 1. 创建采购单 | 补货建议/手动 | purchaser | 补货建议公式（BOM 展开） | draft |
| 2. 下单 | 确认 | purchaser | — | draft → ordered |
| 3. 到货签收 | 货物到达 | receiver | 部分收货、超收授权；触发快进快出匹配 | ordered → partial_received |
| 4. 质检 | 签收后 | receiver | 质检合格/不合格 | → received（质检合格） |
| 5. 上架 | 质检合格 | putaway | 生成上架任务、推荐库位 | → putaway 完成 |
| 5'. 快进快出 | 签收时匹配待打单订单 | receiver | 暂存区直分出库，不入库位 | cross_dock_match → diverted |
| 6. 完成 | 全部到货 | 系统 | 采购单关闭 | → completed |

### 3.4 库存调整与盘点流程

```
[盘点单] → [盘点] → [差异复核] → [授权调整] → [留痕]
```

| 步骤 | 角色 | 系统动作 | 状态流转 |
|---|---|---|---|
| 1. 创建盘点单 | admin | 选范围（全部/库位/SKU） | draft |
| 2. 盘点 | admin | 录入实盘数量 | counting |
| 3. 差异复核 | admin | 计算 book vs actual 差异 | reviewing |
| 4. 授权调整 | admin | **必须授权**，生成 stock_adjustment + 流水 | done + 调整留痕 |

### 3.5 期初上线切换流程

```
[导入文件A] → SKU主数据 + 期初库存(剔标记) + 库位绑定
[导入文件B] → 186 条组合 BOM
[配置规则] → YUN=虚拟 / CS99·CS00·CS000=标记
[补录任务] → ①149无库位SKU上架 ②批次补录 ③17空名称补录 ④8数量不一致人工核对
```

## 四、状态流转汇总（状态机一览）

### 4.1 订单状态机（package.status）

```
unassigned ──分配──► assigned ──拣货──► picking ──复核──► checked ──打包──► packed ──出库──► outbound
     │                  │                 │
     ├─缺货──► shortage_hold              ├─异常──► manual_review
     └─拦截──► intercepted                └─拦截──► intercepted
```

### 4.2 采购单状态机（purchase_order.status）

```
draft ──下单──► ordered ──部分到货──► partial_received ──到齐──► received ──► completed
                                                                    └──► cancelled（可取消）
```

### 4.3 到货单状态机（receiving.status）

```
receiving ──► quality_check ──► qualified（→上架/快进快出）
                              └─► rejected
```

### 4.4 打印队列状态机（print_queue.status）

```
queued ──► printing ──► success
                 └──► failed ──重试──► printing（retry_count 递增）
```

### 4.5 库位状态机（location.status）

```
empty（空） ⇄ occupied（占用） ⇄ full（满）
     └──► locked（锁定）
```

1. **补全后端 API**：13 → 21 个接口（新增上架确认、释放分配、面单标记、拣货任务查询、按包裹查出库单等）

   - **新增 CORS 中间件**（前端跨域调用必需）
   - 前端按钮接口语义修正（recommend 改 POST、outbound_id 按包裹查询、拣货完成走 tasks/complete）

## 四、启动方式

```bash
# 1. PostgreSQL
docker run -d --name wms_pg_test -e POSTGRES_USER=wms -e POSTGRES_PASSWORD=wms \
  -e POSTGRES_DB=wms -p 5433:5432 postgres:15

# 2. 迁移建表
cd wms_backend && export DATABASE_URL="postgresql+psycopg2://wms:wms@localhost:5433/wms"
python3 -m alembic upgrade head

# 3. 后端（端口 8000）
python3 -m uvicorn app.main:app --host 0.0.0.0 --port 8000

# 4. 前端（端口 8080）
cd ../wms_frontend && python3 -m http.server 8080

# 5. 演示数据 + 联调验证
cd ../wms_backend && python3 seed_demo.py && python3 e2e_verify.py
```

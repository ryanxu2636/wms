## 一、任务一句话

为跨境电商卖家设计并落地一套**自建 WMS 仓储管理系统**（完全独立开发、部署在自有服务器），替代店小孺自带 WMS；订单源继续用店小秘，通过 **Excel 导出→导入** 衔接新系统。

## 二、业务背景与核心痛点

1. 订单管理继续用店小秘，仓库作业全部搬到新 WMS。
2. 订单中大量虚拟产品（SKU=`YUN`，即运费虚拟品，占订单行约 57%）不需要发货，店小秘无法隐藏/删除 → 在新系统导入层自动识别打标解决。
3. 店小秘原生 WMS 用「假 SKU 塞备注」当流程标记（见第五节标记 SKU），体验差且污染库存。
4. **完全独立开发，用户自有服务器**（非低代码、非 SaaS）。

## 六、方案 v0.3 核心设计（已确认可用）

### 系统边界
新 WMS = **仓库履约执行层**（收货、库存、库位、拣货、打包、出库、采购、打印），不做第二个订单大脑。订单源=店小秘，一期 Excel 衔接、二期可 API。

### 总体链路
```
店小秘 ──Excel导出──► [导入引擎] 模板识别→字段映射→校验→幂等去重→YUN虚拟过滤→标记SKU规则→预览/错误报告
    ▼
订单中心（状态机：待分配→已分配→拣货中→已复核→已打包→已出库 / 拦截 / 待人工复核 / 缺货挂起）
    ├─→ 库存分配（可用库存锁定）→ 拣货 → 复核 → 打包 → 批量打印面单（云途API，凭运单号）→ 出库
    └─→ 快进快出旁路（到货签收时匹配待打单订单直分，不入库位）
采购模块（采购单→到货→质检→[上架 或 快进快出直分]）──► 库存台账（实时）
库存台账 ◄──► 库位管理（仓库→货架→列→层）◄──► 预警/盘点/报表
```

### 关键设计点
1. **导入幂等**：以「包裹号+SKU」为唯一键；重复导入跳过/覆盖更新；导入预览 + 错误报告（错误行不污染主数据）
2. **虚拟/标记 SKU 规则引擎**（P0 第一优先级）：
   - `YUN` = 虚拟运费 → 免拣货、免库存、免面单，单独视图
   - `CS99/CS00/CS000` = 标记码 → 拦截 / 强制复核 / 采购跳过（配置化，可扩展新暗号）
3. **组合 SKU / BOM**：`sku_type ∈ {基础, 组合, 虚拟, 标记}`；组合 SKU 不设实物库存（虚拟库存 = min(子件可用÷用量)）；订单命中组合 SKU 自动 BOM 展开为拣货明细
4. **实时库存分层**：总库存 = 在途 + 可用 + 已分配 + 锁定/质检；台账流水全程留痕；库存调整必须授权+留痕
5. **批次效期（P0.5）**：SKU 级开关；入库录批次号+生产日期+有效期；出库 FEFO；近效期预警（阈值可配，默认 ≤60 天）；过期锁定
6. **库位**：仓库→货架→列→层（对齐现有 `A07-03-04` 格式）；一品多库位；库位状态空/占用/满/锁定；上架推荐+拣货路径按 货架→列→层 排序
7. **采购**：采购单状态机（草稿→已下单→部分到货→已到货→完成）；部分收货、超收授权；补货建议公式：`建议采购量 = 日均销量×(采购周期+安全天数) − 可用 − 在途 + 已分配`（组合订单按 BOM 展开后计算）
8. **快进快出**：采购到货签收时，匹配"待打单订单"，在收货暂存区直分出库，不入正式库位
9. **面单打印**：批量打包裹标签（包裹号+SKU明细+数量+运单号）；三种包裹类型自动识别（单品单件/单品多件/重复多品，同 SKU 汇总后打印）；打印队列+失败重打+**未打印不允许出库**；二期云途 API 面单（凭运单号，快递单号回填订单）
10. **SLA 预警**：付款时间 + 5 天 = 发货期限，超时预警
